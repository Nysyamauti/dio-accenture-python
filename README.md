# Desafio do Bootcamp "Accenture - Python para Análise e Automação de Dados" da DIO
## Sobre
<p>
  Esse bootcamp tem como missão mostrar aos alunos as possibilidades que a linguagem de programação Python é capaz de realizar no mundo de análise de dados
</p>

## O desafio
<p>
  Um programa que possa identificar as fraudes de números de cartão dentro de um conjunto estabelecido.
  Na prática, houve a necessidade de aplicar técnicas de pré-processamento de dados para torna-las mais precisas, antes de aplicar métodos prontos para esse serviço.
</p>
